# ТЗ: рекомендательная система каталога преподавателей

## 1. Контекст

В сценариях 5 и 7 есть связанные вопросы:

- **№15** — что показывает каталог/лента при открытии, если у ученика есть активные анкеты или их нет;
- **№21** — как каталог работает при нескольких активных анкетах;
- **№24** — какая сортировка используется по умолчанию и как в выдаче ведут себя преподаватели без отзывов.

Эти вопросы нельзя закрывать изолированно: стартовое состояние каталога, переключение между анкетами и порядок преподавателей в выдаче образуют один пользовательский сценарий.

## 2. Проблема предложенных подходов

**Подход 1: сортировать по публичному рейтингу/баллам вклада преподавателя.** Проблема в том, что такой показатель отражает пользу преподавателя для платформы и его активность, но не всегда отражает пользу для конкретного ученика в конкретном запросе. Если сделать его главным фактором сортировки, каталог может начать продвигать не самых подходящих преподавателей, а самых активных в создании контента.

**Подход 2: сортировать только по соответствию параметрам ученика и не опускать преподавателей без отзывов.** Проблема в том, что после применения фильтров все преподаватели уже в некоторой степени соответствуют параметрам, поэтому для порядка внутри выдачи всё равно нужен дополнительный критерий. Если не учитывать доверие, отзывы, активность и вклад преподавателя в платформу, выдача будет слишком плоской и не поможет ученику быстрее выбрать сильных кандидатов.

## 3. Решение

Сортировка по умолчанию в каталоге — **«Рекомендованные»**.

Рекомендательная система сначала применяет фильтры каталога, а затем сортирует подходящих преподавателей по совокупной полезности для ученика. Совокупная полезность не равна одному показателю: она должна учитывать параметры запроса ученика, доверие к преподавателю, активность преподавателя на платформе и наличие образовательного контента.

В v1 рекомендательная система описывается как продуктовая логика. Точные веса, формулы, антифрод, A/B-тесты и автоматическое обучение модели не входят в этот документ.

## 4. Стартовое состояние каталога

### 4.1. У ученика нет активных анкет

При открытии каталога система показывает режим **«Все преподаватели»**.

В выдачу попадают преподаватели, доступные в каталоге. Фильтры анкеты не применяются, потому что активной анкеты нет. Сортировка по умолчанию — «Рекомендованные».

### 4.2. У ученика одна активная анкета

При открытии каталога система автоматически применяет к выдаче параметры активной анкеты:

- предмет;
- бюджет;
- формат занятий;
- город, если выбран офлайн-формат;
- уровень образования ученика.

Эти параметры являются стартовыми фильтрами каталога. Ученик может изменить их вручную или сбросить.

### 4.3. У ученика несколько активных анкет

При открытии каталога стартовым пресетом становится последняя активированная анкета.

Над каталогом показываются чипы активных анкет и отдельный режим **«Все преподаватели»**. При выборе чипа анкеты её параметры подставляются в фильтры каталога. При выборе режима «Все преподаватели» анкетные фильтры сбрасываются.

Ручные изменения фильтров в каталоге не меняют саму анкету.

## 5. Логика рекомендаций

### 5.1. Базовый матчинг

Перед сортировкой система ограничивает выдачу фильтрами каталога.

Если каталог открыт с пресетом анкеты, применяются правила матчинга из сценария 7:

- предмет анкеты входит в предметы преподавателя;
- цена преподавателя попадает в диапазон бюджета анкеты;
- при договорном бюджете ограничение по цене не применяется;
- формат занятий совпадает;
- при офлайн-формате город преподавателя совпадает с городом анкеты;
- преподаватель работает с уровнем образования ученика.

### 5.2. Рекомендательный порядок

После применения фильтров система сортирует преподавателей по рекомендательному скорингу.

Скоринг учитывает:

- точность соответствия параметрам ученика;
- средний рейтинг по опубликованным отзывам;
- количество отзывов;
- наличие подтверждённых данных и квалификации;
- заполненность профиля преподавателя;
- наличие опубликованных материалов, видео или другого образовательного контента;
- активность преподавателя на платформе;
- свежесть активности преподавателя.

Скоринг не должен быть публично представлен как «рейтинг преподавателя». Для ученика это сортировка «Рекомендованные», а не отдельная оценка качества.

## 6. Преподаватели без отзывов

Преподаватели без отзывов не отправляются автоматически в конец выдачи.

Отсутствие отзывов снижает уверенность системы в рекомендации, но может компенсироваться другими факторами:

- полным профилем;
- подтверждённой квалификацией;
- точным совпадением с параметрами ученика;
- опубликованными материалами или видео;
- свежей активностью на платформе.

Такое правило нужно для того, чтобы новые преподаватели могли получить первые показы и первые отзывы. Иначе возникает замкнутый круг: нет отзывов → мало показов → нет учеников → нет отзывов.

## 7. Баллы вклада преподавателя

Баллы вклада преподавателя в платформу могут использоваться как один из факторов рекомендательного скоринга.

Этот показатель не заменяет средний рейтинг по отзывам и не должен называться рейтингом преподавателя. Его смысл — отразить вклад преподавателя в развитие платформы: создание материалов, видео, скринкастов, участие в образовательном контенте, доработку материалов и другие подтверждённые действия.

Возможные названия показателя:

- XP;
- баллы профиля;
- вклад в платформу;
- активность на платформе.

В v1 показатель можно использовать внутри рекомендательной сортировки, но его публичность, точное название и правила начисления требуют отдельного сценария.

## 8. Ручные сортировки

Помимо сортировки «Рекомендованные», ученику доступны ручные сортировки:

- по цене по возрастанию;
- по цене по убыванию;
- по рейтингу;
- по количеству отзывов;
- новые преподаватели.

Ручная сортировка меняет только порядок текущей выдачи. Применённые фильтры при этом сохраняются.

Если ученик выбирает сортировку по рейтингу, преподаватели без отзывов показываются после преподавателей с рейтингом. В сортировке «Рекомендованные» такого автоматического правила нет.

## 9. Правила и ограничения

1. Сортировка по умолчанию всегда называется «Рекомендованные».
2. Рекомендательная сортировка не должна сводиться к одному фактору: рейтингу, количеству отзывов, свежести или баллам вклада.
3. Баллы вклада преподавателя не заменяют отзывы и не являются публичной оценкой качества преподавателя.
4. Преподаватели без отзывов участвуют в рекомендательной выдаче на общих основаниях.
5. Параметры анкеты при открытии каталога используются как стартовый пресет фильтров, а не как отдельная сущность «подборки».
6. Ручные изменения фильтров в каталоге не изменяют анкету ученика.
7. Режим «Все преподаватели» сбрасывает анкетные фильтры и показывает общий каталог с сортировкой по умолчанию.

## 10. Не входит в v1

- точная формула скоринга;
- веса факторов;
- персонализация на основе истории просмотров и переписок;
- A/B-тесты порядка выдачи;
- антифрод для отзывов, просмотров и контента;
- автоматическое начисление баллов за просмотры внешних видео;
- машинное обучение;
- платное продвижение преподавателей.
