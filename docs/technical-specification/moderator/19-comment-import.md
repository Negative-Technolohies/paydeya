## 19. Добавление отзывов на преподавателей из других платформ

### 19.1. Назначение

Процесс позволяет преподавателю добавить в свой профиль отзывы о себе с других платформ. Преподаватель указывает ссылки на свои публичные профили и количество отзывов. Модератор проверяет ссылки; после одобрения система автоматически импортирует отзывы через отдельный парсер (внешний сервис). Импортированные отзывы отображаются в профиле с пометкой об источнике и ссылкой на оригинал.

Внешние отзывы учитываются в общем рейтинге преподавателя наравне с внутренними отзывами.

### 19.2. Участники, пред- и постусловия

**Участники:**

- преподаватель (инициатор запроса);
- модератор платформы с правом `import_external_reviews` (проверяет ссылки и запускает импорт);
- система (управляет запросами, запускает парсер, сохраняет отзывы, пересчитывает рейтинг);
- парсер внешних платформ (автоматизированный сбор отзывов по ссылке).

**Предусловия:**

- преподаватель авторизован и не забанен;
- у преподавателя подтверждена личность (в `tutor_verifications` есть активная запись с `type = 'passport'`);
- существует хотя бы один модератор с правом `import_external_reviews`;
- преподаватель заполнил и отправил форму запроса.

**Постусловия (успешное завершение):**

- импортированные отзывы сохранены в таблице `external_reviews` и отображаются в профиле преподавателя с пометкой источника;
- рейтинг преподавателя пересчитан с учётом внешних отзывов;
- запрос помечен как выполненный;
- преподаватель получает уведомление об успешном импорте.

**Постусловия (при отклонении):**

- запрос отклонён, импорт не выполняется;
- преподаватель получает уведомление с причиной.

### 19.3. Входные данные

**Форма запроса от преподавателя:**

| Поле                                  | Обязательность | Валидация                                                                                                   |
| ------------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------- |
| Название платформы                    | обязательно    | выбор из списка поддерживаемых платформ (например, Profi.ru) или свободный ввод, если платформа не в списке |
| Ссылка на профиль/страницу с отзывами | обязательно    | корректный URL, страница должна быть публичной                                                              |
| Количество отзывов на платформе       | обязательно    | целое число ≥ 1                                                                                             |

**Решение модератора:**

| Поле        | Обязательность          | Валидация                                             |
| ----------- | ----------------------- | ----------------------------------------------------- |
| Решение     | обязательно             | `approve` (запустить импорт) или `reject` (отклонить) |
| Комментарий | обязателен при `reject` | до 1000 символов                                      |

### 19.4. Основной процесс

**Подача запроса преподавателем:**

1. Преподаватель в своём профиле в разделе «Отзывы» видит опцию «Добавить отзывы с других платформ». Если личность не подтверждена, опция отображается серой с подсказкой при наведении: «Сначала пройдите верификацию личности».
2. Если верификация пройдена, преподаватель нажимает на опцию, заполняет форму: платформа, ссылка, количество отзывов.
3. Нажимает «Отправить».
4. Сервер сохраняет запрос в таблице `external_review_requests` со статусом `pending` и полями: `platform_name`, `url`, `declared_count`.
5. Сервер отправляет уведомление модераторам с правом `import_external_reviews`.

**Обработка запроса модератором:**

1. Модератор открывает уведомление, переходит к запросу.
2. Видит платформу, ссылку, заявленное количество отзывов.
3. Переходит по ссылке, проверяет, что страница публично доступна и принадлежит данному преподавателю (по ФИО, фото, описанию).
4. Если платформа не поддерживается парсером или страница требует авторизации — модератор отклоняет запрос с комментарием о невозможности импорта.
5. Если всё корректно:
   - Модератор нажимает «Одобрить» (`approve`).
   - Сервер запускает парсер для указанной платформы, передавая ссылку.
   - Парсер собирает отзывы (текст, оценку, ссылку на оригинал, если доступна) и возвращает их системе.
   - Система создаёт записи в таблице `external_reviews` для каждого импортированного отзыва.
   - Сервер пересчитывает рейтинг преподавателя (среднее арифметическое всех внутренних и внешних отзывов).
   - Статус запроса становится `completed`, `processed_at` устанавливается.
   - Преподаватель получает уведомление об успешном добавлении отзывов.
6. Если ссылка некорректна, страница не принадлежит преподавателю, количество не совпадает и т.п.:
   - Модератор нажимает «Отклонить» (`reject`) и указывает причину.
   - Запрос получает статус `rejected`.
   - Преподаватель получает уведомление с причиной.

### 19.5. Ошибочные и альтернативные ветки

1. **Преподаватель не верифицирован.**  
   Опция серая, форма не открывается; при наведении показывается подсказка.

2. **Ссылка ведёт на недоступную страницу или требует авторизацию.**  
   Модератор отклоняет запрос с комментарием. Платформы, требующие авторизацию, не поддерживаются в v1.

3. **Количество отзывов на странице не совпадает с заявленным.**  
   Модератор может отклонить запрос или одобрить, указав в комментарии, что количество будет уточнено автоматически. Парсер импортирует фактическое число отзывов.

4. **Парсер не смог собрать отзывы (ошибка, изменение структуры сайта).**  
   Запрос переходит в статус `failed`, преподаватель и модератор уведомляются. Можно повторить позже.

5. **Платформа не поддерживается парсером.**  
   В v1 поддерживается ограниченный список (например, Profi.ru). Для остальных запрос отклоняется с сообщением о невозможности импорта.

6. **Преподаватель хочет отозвать запрос до обработки.**  
   Разрешается, статус `cancelled`.

### 19.6. Правила и ограничения

1. Право на обработку запросов — `import_external_reviews`.
2. Добавление внешних отзывов доступно только преподавателям с подтверждённой личностью.
3. Импорт выполняется автоматическим парсером. Модератор только проверяет ссылку и запускает процесс.
4. Внешние отзывы хранятся в отдельной таблице `external_reviews` и не смешиваются с внутренними отзывами, но учитываются в общем рейтинге.
5. Рейтинг преподавателя пересчитывается с учётом всех опубликованных внутренних и внешних отзывов.
6. Ссылка на оригинальный отзыв сохраняется, если парсер может её получить.
7. Запрос обрабатывается одним модератором; после завершения не редактируется.
8. Все действия логируются.

### 19.7. Изменения модели данных

**Таблица `external_review_requests`:**

| Поле           | Тип                                            | Комментарий                                                                         |
| -------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------- |
| id             | BigInteger, PK                                 |                                                                                     |
| tutor_id       | BigInteger, FK → `tutor_profiles.id`, NOT NULL |                                                                                     |
| platform_name  | String, NOT NULL                               | название платформы                                                                  |
| url            | String, NOT NULL                               | ссылка на профиль/страницу с отзывами                                               |
| declared_count | Integer, NOT NULL                              | заявленное количество отзывов                                                       |
| status         | String, NOT NULL, default 'pending'            | `pending`, `approved`, `rejected`, `processing`, `completed`, `failed`, `cancelled` |
| moderator_id   | BigInteger, FK → `users.id`, NULL              | модератор, обработавший запрос                                                      |
| comment        | String(1000), NULL                             | комментарий модератора                                                              |
| created_at     | datetime, NOT NULL                             |                                                                                     |
| processed_at   | datetime, NULL                                 |                                                                                     |

**Таблица `external_reviews`:**

| Поле          | Тип                                                      | Комментарий                                            |
| ------------- | -------------------------------------------------------- | ------------------------------------------------------ |
| id            | BigInteger, PK                                           |                                                        |
| tutor_id      | BigInteger, FK → `tutor_profiles.id`, NOT NULL           |                                                        |
| request_id    | BigInteger, FK → `external_review_requests.id`, NOT NULL | из какого запроса импортирован                         |
| platform_name | String, NOT NULL                                         |                                                        |
| author_name   | String, NULL                                             | имя автора отзыва на внешней платформе (если доступно) |
| rating        | Integer, NOT NULL                                        | оценка 1–5                                             |
| text          | String(2000), NOT NULL                                   | текст отзыва                                           |
| source_url    | String, NULL                                             | ссылка на оригинальный отзыв (если доступна)           |
| created_at    | datetime, NOT NULL                                       | время импорта                                          |

**Права:**

- `import_external_reviews` — новое право.

**Индексы и ограничения:**

- В `external_review_requests` — индекс по `(tutor_id, status)`.
- В `external_reviews` — индекс по `(tutor_id, request_id)`.
